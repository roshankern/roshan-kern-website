# Systemic

Every script in this area is **illustrative** (`illustrative: true`). Blood-cell size, IgE and mucosal edema can't be shown literally on an adult anatomy mesh, so each effect is a stylized per-part tint, swell or scale on the site of the finding. Each row below still names the real physiology that the effect stands in for. Where the record gives the fact (a date, a lab value, how long a reaction lasted), the record is quoted first. Code: `app/anyhealth/timeline/issues/catalog/systemic.ts` and `issues/systemic/*`.
